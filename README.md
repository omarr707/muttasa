# مُتَّسَع

تطبيق جوال عربي يحوّل روتينك واختياراتك إلى جدول يومي قابل للتنفيذ، ويبيّن لك مدى التزامك مع الوقت.

> رتّب يومك، وخلّ فيه وقت للناس اللي يهمّونك.

## الحالة

هذا الفرع يحتوي **المرحلة الأولى** بالتصميم البصري المعتمد (الجولة الثانية): التطبيق يعمل على الجهاز بالكامل، بدون حساب وبدون مزامنة.

| موجود الآن | يجي لاحقًا |
|---|---|
| التهيئة بسؤال في كل شاشة: المدينة، كيف يمشي يومك، الاهتمامات، الملخص | الأهداف بالنتيجة والموعد، الختمة، الادخار (المرحلة ٢) |
| يومي: الجدول، شريط «فاتت» وورقة القرار، ورقة الماء بالمل، «جمعة مباركة»، زرّان عائمان | التقارير الشهرية والسنوية (المرحلة ٢) |
| التواصل مع الناس: الأشخاص والتكرار والمناسبات، واقتراحات اتصال ورسائل داخل يومي | المواسم ورمضان والأوضاع (المرحلة ٣) |
| روتيني: تعديل بإصدارات مؤرخة مع معاينة أثر التغيير | الحساب والمزامنة ولوحة الإدارة (المرحلة ٤) |
| الصلوات والسنن، الأذكار، الورد بالصفحات، العادات X مرات بالأسبوع | |
| الإنجاز اليومي والأسبوعي، الإحصائيات حسب النوع | |
| الإعدادات بأربع مجموعات، والمظهر: الثيم وحجم الخط والأرقام ١٢٣/123 | |
| الإشعارات المحلية مع حد يومي وساعات هدوء | |
| قاعدة بيانات مشفرة، نسخ احتياطي واستعادة بملف | |

## البنية

```
packages/schedule_core/   محرك الجدولة: Dart خالص بدون Flutter، ومعه اختباراته
lib/
  core/       رموز دليل التصميم (الألوان، سلّم الخطوط، الزوايا) والعناصر المشتركة
  data/       قاعدة البيانات (Drift + SQLite3MultipleCiphers) والمستودع والإعدادات الافتراضية
  state/      الحالة (Riverpod) وكل أفعال المستخدم
  features/   الشاشات: onboarding · day · routine · goals · settings (ومعها التواصل)
  services/   الإشعارات والنسخ الاحتياطي
assets/defaults/config.json   الدول والمدن وطرق الحساب وعطلة الأسبوع
```

### فكرة المحرك

- القواعد تُخزَّن بإصدارات مؤرخة (`validFrom`/`validTo`)، فتعديل الروتين «من اليوم» ما يغيّر الأيام الماضية.
- جدول اليوم **يُولَّد** من القواعد ولا يُخزَّن. اللي يُخزَّن فقط: تعديلات المستخدم على يوم معيّن، والسجل (تمت/فاتت/أُجّلت)، والمهام لمرة واحدة.
- كل سجل مفتاحه `(التاريخ، مفتاح العنصر)`، لذلك إعادة التوليد تحافظ على تعديلات المستخدم.
- العناصر توضع على شبكة ٥ دقائق، والمواعيد الثابتة لها الأولوية، والمرنة تُوزَّع في الوقت الفاضي ضمن الفترة المختارة.

## التشغيل

يحتاج Flutter 3.50 أو أحدث.

```bash
flutter pub get
flutter run
```

الاختبارات:

```bash
(cd packages/schedule_core && dart test)   # المحرك
flutter test --exclude-tags screens        # التطبيق
flutter test --tags screens --update-goldens   # لقطات الشاشات في test/goldens
```

بعد تعديل جداول قاعدة البيانات:

```bash
dart run build_runner build
```

## نسخة للجوال

كل تحديث على الفرع يبني APK للأندرويد تلقائيًا عبر GitHub Actions، وينشره في صفحة **Releases** كنسخة تجريبية. للآيفون تحتاج حساب Apple Developer و TestFlight.

## ملاحظات المرحلة الأولى

- أزرار الإشعار («تمت»، «بعد ١٠ دقائق») تفتح التطبيق ثم تنفّذ.
- الإشعارات تُجدول لثلاثة أيام قادمة كل ما فتحت التطبيق، فلو ما فتحته أكثر من ثلاثة أيام تتوقف حتى تفتحه.
- معرّف التطبيق مؤقت (`app.muttasa`) حتى يُحسم اسم المتجر.
